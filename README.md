# Tetris

A small, browser-style Tetris game written in Python. It uses Tkinter, which is included with most standard Python installations, so there are no third-party packages to install.

## Run it

Open a terminal in this folder and run:

```bash
python tetris.py
```

On Windows, you can also run `py tetris.py`.

## Controls

- **Left / Right arrows**: move
- **Up arrow**: rotate
- **Down arrow**: soft drop
- **Space**: hard drop
- **P**: pause or resume
- **R**: restart

The game includes a next-piece preview, scoring, line clears, increasing speed, and a seven-piece randomizer.
